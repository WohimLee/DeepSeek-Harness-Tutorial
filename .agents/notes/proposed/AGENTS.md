# Proposed Agent Notes

本目录只保存尚未完整落地的重大提案。遵循根 `AGENTS.md` 和 `../README.md`，将 Note 放入与
决策类别一致的子目录。

新 Note 从 `../template.md` 开始，使用 `Status: proposed`，并包含 Problem、Proposal、
Alternatives considered、Acceptance criteria 和 Risks。提案不是当前工程规范；代码和当前
文档不得把未实现的内容描述为已有能力。

落地完成后移动到 `../implemented/<class>/`，将 Proposal 改写为现在时的 Decision，并把
验收条件更新为实际验证证据。被否决时移动到 `../rejected/<class>/` 并写明简短原因。
